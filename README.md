# Study-Bench · 学习工作台

> 面向三人竞赛团队（智能车 / 电赛）的学习打卡与进度管理网页。
> 按「基础夯实 → 单项技能 → 实战练手 → 竞赛冲刺」组织学习路线，逐节课时与练手项目里程碑可视化推进，三人分工、互相监督。

纯前端单页应用，**无构建、无框架、无 CDN、无 npm 依赖**；另附一个零依赖 Node 服务，用于局域网内三人实时同步。

## 特性

- **开箱即用**：双击 `index.html` 就能跑；三人共用只需一条 `node server.js`。
- **进度从零开始**：初始无任何打卡与完成记录，路线与分工已排好，团队自己推进。
- **逐节可视化**：每个模块含课时圆点与项目里程碑节点，点一下即推进，自动算百分比。
- **分工与权限**：模块只有负责人可编辑，他人只读；团队视图横向对比三人投入与通关情况。
- **实时同步**：局域网内打卡 / 课时 / 改名每 4 秒自动同步，按 id 并集合并，不覆盖他人进度。
- **离线也能协作**：无局域网时用「分享码」把进度发给队友合并。
- **三套主题**：PCB 工作台（暗绿硬核）/ Claude 暖纸 / Claude 暖夜，本机记忆、切换无闪烁。
- **数据可带走**：一键导出 / 导入 JSON 备份，数据不锁在任何一个浏览器里。

## 快速开始

### 模式 A · 本机离线（单人 / 试用）

直接用浏览器打开 `index.html`（`file://` 协议）。

- 自动进入**本地模式**，数据存浏览器 `localStorage`，刷新不丢。
- 登录页**点击成员卡片即可免密进入**，无需密码。
- 多人不共享数据；适合单人使用或先熟悉界面。

### 模式 B · 局域网实时同步（三人共用）

```bash
cd Study-Bench          # clone 下来的目录名
node server.js          # 需要本机装有 Node.js，无需 npm install
```

- 启动后命令行打印本机与局域网地址，例如 `http://192.168.x.x:8787`。
- 三人浏览器访问该地址 → 点击各自成员卡片进入 → **共享一份团队数据**。
- 打卡 / 课时进度每 **4 秒**自动同步，写入防抖 350ms。
- 端口可用环境变量覆盖：`PORT=9000 node server.js`。
- 数据落在 `data/team.json`（写临时文件再原子替换，避免写一半被读到）。
- 首次启动会自动生成初始数据；该文件已 gitignore，不进仓库。

> 模式是自动探测的：`file://` 打开一律本地模式；否则先探测 `/api/ping`，探测成功进入服务模式，失败回落本地模式。

### 默认成员

| id | 默认名 | 方向 |
|---|---|---|
| `me` | 我 | 视觉算法 · 控制主线 · 龙芯 |
| `a` | 队友 A | 硬件 PCB · 电源驱动 · 机械 |

## 数据与备份

### 数据存在哪

| 模式 | 位置 | 说明 |
|---|---|---|
| 本机离线 | 浏览器 `localStorage`（键 `studybench.v2`） | 只属于当前浏览器；清缓存 / 换浏览器会丢，请定期导出备份 |
| 局域网同步 | 服务端 `data/team.json` | 三人共享一份；已 gitignore，不入公开仓库 |

另有两个本机键：`studybench.session`（登录身份）与 `studybench.theme`（主题），均不影响团队数据。

### 导出 / 导入

「数据」视图可导出完整团队 JSON 备份，或导入备份覆盖当前数据。导出内容只含团队学习数据，不含任何凭据。

### 分享码（无局域网时离线合并）

- 生成分享码 → 发给队友 → 队友粘贴合并，双方打卡与课时进度按 id **并集汇总**。
- 前缀 `SBX1.`（gzip 压缩）/ `SB1.`（旧浏览器无压缩回退）。
- 解码 `SBX1.` 需要浏览器支持 `DecompressionStream`，请用较新版 Chrome / Edge。
- 并集语义意味着**已删除的模块可能被对方的分享码带回来**，合并前请确认。

### 同步与合并规则（服务模式）

- 改动 → 防抖 350ms → 写入 → 版本号 `rev` +1；每 4 秒轮询，`rev` 变化则合并重渲染。
- 合并按 id **并集**，不覆盖本地：课时 / 里程碑的完成态取「或」、时间戳取较新；打卡与硬件按时间戳取较新。
- 弹窗打开或输入框聚焦时暂停轮询，避免打断编辑。
- 服务重启后登录会话失效，需重新点击成员卡片进入。

### 重置

「数据 → 重置全部数据」会清空所有修改与打卡记录，恢复 31 个主线模块、57 条资料、16 项硬件，**进度归零**并按默认分工重新指派。操作前建议先导出备份。

## 部署注意事项与安全边界

**安全模型是「信任局域网」**，为可信三人小队设计，不是公网服务：

- **免密登录**：点击成员卡片即进入，没有任何口令概念。
- **改名接口公开**：名称属公开团队数据，任何访问者可改。
- **`GET /data/team.json` 无需鉴权即返回完整团队数据**（静态托管的既有行为）。

因此：

- 只在可信局域网（宿舍 / 实验室 / 队伍热点）内运行，**不要把 `server.js` 暴露到公网**或做端口映射。
- 接入不可信网络前必须先堵上静态目录暴露（给静态路由加 `data/` 黑名单，或把数据目录移出托管根目录），并补鉴权与限流。
- 部分校园 / 企业 AP 开启了「客户端隔离」，会导致队友访问不到主机。此时改用分享码离线合并，或换一个允许互访的网络 / 手机热点。
- 服务监听 `0.0.0.0`，同一台机器上的其他用户也能访问，注意主机本身的访问控制。
- 单服务实例、无并发写锁，靠版本号 + 轮询合并；极端同时写以最后一次写入为准（打卡与课时按 id 并集，不会丢）。

## 项目结构

```
Study-Bench/
├─ index.html      # 页面骨架：7 个视图容器 + 登录遮罩 + 弹窗/抽屉/toast + 防主题闪烁脚本
├─ styles.css      # 全部样式：CSS 变量主题系统（3 主题）+ 组件 + 响应式
├─ app.js          # 前端全部逻辑：状态 / 渲染 / 交互 / 同步 / 分享码
├─ seed.js         # 共享种子：成员 / 阶段 / 模块库 / 硬件 / 资料 / 版本迁移（前后端共用）
├─ server.js       # 零依赖局域网同步服务：静态托管 + 会话鉴权 + 团队状态读写
├─ data/           # 服务端数据目录（运行时生成，已 gitignore）
├─ .gitignore
└─ README.md
```

| 项 | 内容 |
|---|---|
| 技术栈 | 原生 HTML / CSS / JavaScript，无构建、无框架、无 CDN、无 npm 依赖 |
| 服务端 | 仅用 Node 内置模块（`http` / `fs` / `path` / `os` / `crypto`） |
| 数据 schema | v4；旧版本数据在读取时自动增量升级，保留真实打卡与自定义模块 |
| 会话 | 内存态，有效期 7 天；请求体上限 8 MB |
| 仓库 | `https://github.com/idswsy/Study-Bench.git`，分支 `main` |

`seed.js` 用 UMD 包装：浏览器里挂 `window.SEED`，Node 里走 `module.exports`。**改学习内容只改这一个文件**，前后端同时生效。

## 内容约定

新增或修改学习内容时请沿用以下约定：

- **URL 只用核实过的**：教程链接均已搜索核实；构造的站内搜索链接一律标注「搜索直达」，不冒充具体资源。
- **课时时长一律留空**（`dur: ''`），不编造时长。
- **器件与平台写准确**：星瞳 = OpenMV 官方；MaixCam2 = Sipeed MaixPy（爱芯 AX630C，非 K230）；MSPM0G3507 = TI 官方 LaunchPad（非立创）。
- **模块 id 用确定性 id**（= 模块库模板 id），课时 / 项目 / 里程碑 id 随模板保留 —— 这是跨设备去重的依据，改 id 策略会破坏合并。
- 文本字段有长度上限，超限会被静默截断（模块名 30 / 成员名 20 / 目标 200 / 课时标题 90 / 作者 30）。
